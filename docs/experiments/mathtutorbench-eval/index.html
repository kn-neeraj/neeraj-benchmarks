EXPERIMENT 01 · model-comparison · In progress

MathTutorBench: Hard Scaffolding

Three open-weight models write the next tutor turn in a math dialog; an LLM judge scores each turn against the real human teacher's response.

2026-08-30
01

Task

Each item is a math problem plus a partial student/teacher dialog. The model under test writes the next teacher turn (max 2 sentences) without giving away the answer.

02

Results — Judge score

0–1 score from an LLM judge (Qwen3.8-Max) comparing the model's turn to the real human teacher's turn; 0.50 means judged equal to the human.

02

Notes & limitations

  • Judge, judge prompt, and reasoning-effort settings differ from Braintrust's original eval (not public), so exact score values are not expected to match — rank order and CI overlap are what's comparable.
  • Judge is Qwen3.8-Max, deliberately not one of the three models under test, to reduce self-preference and shared-lineage bias.
  • Results shown are the reasoning_effort=none condition; see the experiment README for the full run design.
